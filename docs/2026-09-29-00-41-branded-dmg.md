# Branded install disk image

## Summary
Give Retriever a Finder install layout comparable to Capture, using warm colors, a drag arrow and installation instructions.

## Product behavior target
Opening the DMG shows the real Retriever app at left and Applications shortcut at right, aligned to a branded background. Dragging installs the app.

## Architecture changes
Native AppKit background renderer and a dedicated DMG creation helper with Finder AppleScript layout. The release pipeline signs/notarizes the final styled image after creating it. Unique staging/mount paths; preserve evidence and fail if Finder layout is not saved.

## UX acceptance criteria
Readable install instructions, aligned icons and arrow, hidden background folder, saved Finder icon view and fixed window size.

## Automated test plan
Render and inspect background, create an unsigned preview from the built app, mount and inspect layout/background/symlink. Check syntax and release publication regression.

## Manual verification plan
Inspect mounted Finder window. Finder automation may require permission. Preview is separate from the published signed DMG.

## Assumptions and non-goals
No app behavior changes or artwork generation needed; use native vector drawing for this simple layout. Do not modify an existing signed artifact in place.

## Results
Native background renderer passed. Styled unsigned preview created, hdiutil checksum verified, and final compressed image reopened in Finder. Screenshot inspected; hidden support files moved offscreen for users with Show Hidden Files enabled. Final artwork aligns the arrow with the reopened icon positions and raises the footer above scrollbars. Publication regression checks passed. The existing notarized website DMG is unchanged; rerun make release to produce a signed version of this layout.

Final compressed preview was reopened and visually inspected after spacing changes. Background, .DS_Store and /Applications symlink were verified. Existing mounted Retriever volumes are rejected before creation to prevent Finder alias ambiguity.
