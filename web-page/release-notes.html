Send files to your server.

Upload a file from your Mac to the current remote folder, with progress, cancellation, and confirmation before replacing an existing file.

Upload from the file browser

  • Choose Upload in the toolbar or File menu, or press ⌘U, then select a local file.
  • Retriever uploads to the folder shown above the file list.
  • See how many bytes have been sent. Use Cancel or ⌘. to stop the transfer.
  • After the upload completes, the file list refreshes and selects the uploaded file.

Choose when to replace a file

  • If a file with the same name exists on the server, choose Cancel or Replace.
  • Retriever finishes uploading a temporary copy before replacing the existing file.
  • Replacement requires server support for atomic rename. If that support is unavailable, the existing file stays untouched.

Know what happened if a transfer stops

  • Ordinary file errors leave the connection available when possible.
  • Retriever removes incomplete uploads when the connection can still be used safely.
  • If a connection failure prevents cleanup, an alert identifies the temporary remote file that may remain.
  • If the server may have completed the upload before the connection failed, Retriever asks you to check the destination before retrying.

Requires macOS 14 or later. Uploads support one regular file at a time; folders and symbolic links are not supported. Uploaded files allow only their owner to read and write them. Uploads do not appear in Downloads history. FTP remains unsupported.

Browse, preview, and keep track of downloads.

Use the keyboard to browse and preview files, find completed downloads, and continue browsing after file errors.

Browse and preview with the keyboard

  • Press Space to preview the selected file. Press Escape to close the preview or cancel its download.
  • Arrow keys keep working after you expand a folder. Refresh preserves the selected file and expanded folders where available.
  • Files larger than 1 MB, or with an unknown size, require confirmation before preview. Retriever also checks the limit during download.

Find previous downloads

  • Open Downloads from the toolbar or Window menu, or press ⇧⌘J.
  • View completed downloads with their server, date, and size. Use Show in Finder to reveal a downloaded file.
  • Download history stays available after you restart Retriever. Clear History removes the records and keeps your files.
  • Previews, failed downloads, and cancelled downloads are not added to history.

Replace files and recover from errors

  • Choose Replace in the macOS Save dialog to overwrite an existing file after the download completes.
  • If the download fails or is cancelled, the existing file stays intact.
  • Ordinary file errors keep the connection available when possible.
  • If the connection is lost, the file list stays visible. Choose Reconnect to continue browsing.

Requires macOS 14 or later. FTP, uploads, folder downloads, and symbolic-link downloads remain unsupported.

Pick up where you left off.

Return to saved servers, expand folders in place, and preview files from the context menu.

Screenshots use sample connection details and files.

Saved hosts and folders

  • Successful connections are saved automatically with each host’s last visited folder.
  • Choose a saved host in Open Connection, edit its starting folder, or use Forget to remove it.
  • If a saved folder is unavailable, Retriever opens the server’s home folder and shows a notice.
  • Passwords are never saved. Retriever does not connect automatically when it starts.

Browse an expandable file tree

  • Click a folder’s arrow to expand or collapse it within the file list.
  • Browse nested folders and download their files without leaving the current directory.
  • Larger disclosure arrows and vertically centered labels make rows easier to read.

Preview from the context menu

  • Right-click a file for Download or Preview.
  • Download opens the existing macOS Save dialog.
  • Preview retrieves a temporary copy and displays it in native Quick Look.
  • Temporary preview files are removed when the preview closes, is replaced, or the app quits. Preview downloads can be cancelled.

A consistent app icon

  • The Dock and About panel show the Retriever icon with a rounded tile and transparent outer corners.

Requires macOS 14 or later. FTP, uploads, folder downloads, and symbolic-link downloads remain unsupported.

Meet Retriever.

A native Mac app for connecting to an SFTP server, browsing its folders, and downloading individual files.

Connect and browse

  • Connect using SSH keys, an SSH agent, or a password.
  • Verify a new server’s fingerprint before connecting.
  • Navigate folders and view file names, sizes, and modification dates.

Download with control

  • Choose a destination with the native macOS Save dialog.
  • See how many bytes have been received and cancel active work.
  • Preserve existing files and remove partial downloads after cancellation.

Made for macOS

  • Native menus, keyboard shortcuts, Help, and authentication dialogs.
  • macOS 14 or later; Apple silicon and Intel builds.
  • This version supports SFTP and individual file downloads. FTP, uploads, folder downloads, and symlink downloads are not supported.
