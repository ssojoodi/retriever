Just the essentials

Your server.
A familiar file browser.

One connection, a clear file list, and a Download button. Built with native Mac controls that stay out of your way.

  • ↗
    Connect with SSHUse your SSH keys, agent, or password. Check the server fingerprint before trusting a new connection.
  • ▤
    Find your filesBrowse folders, go up a level, and refresh the listing. See file sizes and modification dates at a glance.
  • ↓
    Bring a file homeChoose where to save it with the macOS Save dialog. Cancel a transfer when you need to; partial downloads are cleaned up.

Three simple steps

From your server to your Mac.

1

Open a connection

Enter your server, username, and SFTP port. Verify the server’s fingerprint when prompted.

2

Browse to your file

Open folders in the file list. Use Up to return to the parent folder.

3

Download

Select a file, choose Download, and pick a new local filename. Existing files are preserved.

Install

Right at home on your Mac.

Open the downloaded DMG and drag Retriever to Applications. Launch Retriever and choose Open Connection.

Requires macOS 14 or later and an SFTP server. This first version downloads individual files; FTP, uploads, and folder downloads are not supported.
