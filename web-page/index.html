Download for Mac ↓ How it works

Just the essentials

Your server.
A familiar file browser.

Return to your last folder, browse an expandable file tree, and preview a file before saving it. Built with native Mac controls.

  • ↗
    Connect with SSHUse your SSH keys, agent, or password. Check the server fingerprint before trusting a new connection.
  • ▤
    Return to your saved hostsSuccessful connections are saved with each host’s last visited folder. Reconnect without retyping the details. Passwords are never saved.
  • ▸
    Expand folders in placeOpen folders within the file tree. Browse nested files while keeping the parent folder in view.
  • ◉
    Preview before downloadingRight-click a file and choose Preview to open a temporary copy in native Quick Look. Close the preview to remove the copy.
  • ↓
    Bring a file homeChoose where to save it with the macOS Save dialog. Cancel a transfer when you need to; partial downloads are cleaned up.
  • ↑
    Send a file to your serverChoose Upload or press ⌘U. Track progress, cancel a transfer, and confirm before replacing a remote file.

Three simple steps

Between your Mac and your server.

1

Open a connection

Choose a saved host or enter a server, username, and SFTP port. Verify a new server’s fingerprint when prompted.

2

Browse to your file

Reconnect to your last folder. Click folder arrows to expand the tree, or double-click a folder to open it.

3

Transfer your file

Preview or download a remote file, or choose Upload (⌘U) to send a local file to the current folder.

Install

Right at home on your Mac.

Open the downloaded DMG and drag Retriever to Applications. Launch Retriever and choose Open Connection.

Requires macOS 14 or later and an SFTP server. Retriever previews, downloads, and uploads individual files. FTP, folder transfers, and symbolic-link transfers are not supported.
